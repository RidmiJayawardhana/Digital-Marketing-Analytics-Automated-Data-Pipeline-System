# 🚀 Digital Marketing Analytics & Automated Data Pipeline System

## 📌 Project Overview

This project demonstrates a complete digital marketing analytics workflow integrated with an automated data engineering pipeline. The system captures user interactions from a landing page, tracks campaign performance using Google Analytics 4 (GA4), and processes analytics data through Apache NiFi pipelines.

The project combines **Digital Marketing Analytics**, **Campaign Tracking**, and **Real-Time Data Processing** into a single end-to-end implementation.

---

## ✨ Features

### 🌐 Landing Page & User Interaction

* Built a landing page using Google Sites
* Created structured navigation pages
* Developed a registration form using Google Forms

### 📊 Google Analytics 4 (GA4)

* Integrated GA4 tracking
* Monitored real-time visitors
* Analyzed user engagement and sessions
* Tracked traffic sources and user behavior

### 📈 Campaign Tracking

* Created UTM campaign links
* Tracked Facebook, Email, and WhatsApp campaigns
* Monitored campaign performance and conversions

### ⚙️ Apache NiFi Data Pipeline

* Built automated data pipelines using Apache NiFi
* Extracted analytics data using InvokeHTTP
* Managed attributes using UpdateAttribute
* Stored processed data using PutFile
* Enabled automated real-time data flow
